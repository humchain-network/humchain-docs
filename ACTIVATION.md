# Territory Activation - HumChain Network

### Core Principle
Territory does not pre-exist in HumChain. It is activated.

The network starts empty: `activated_territories = []`

### What is a Territory?
A Territory is a sovereign state recognized by ISO 3166-1.

Reference in the real world today: 249 territories (ISO + UN).

This number is NOT locked in the protocol. It is an external reference.
The protocol only counts territories actually activated by humans.

### The First Human Rule
The first verified human according to the HumChain Registration Protocol activates his Territory.

- 1 verified human = Territory ACTIVATED
- No threshold, no committee, no permission

He becomes the Genesis Human of that territory.

### The Empty Start Rule
- No pre-mine
- No pre-allocation
- No waitlist

`total_supply = 0` at Genesis. Supply is created only by activation.

### Upon Activation
When the first human is verified, ONE identical allocation is minted for that territory:

**473,933,649 HCN - Fixed. Equal for all.**

This allocation is distributed per Economic Constitution Title V:

- 323,933,649 HCN - Community Mining (Proof-of-Humanity)
- 25,000,000 HCN - National Treasury
- 50,000,000 HCN - Public Sale and Ecosystem Access
- 75,000,000 HCN - Protocol Development, Validators, and Merchant Financing

The Genesis Human does NOT own this supply. He only ACTIVATES it for his territory.

- 1st territory activated (e.g., CM) = 473,933,649 HCN
- 200th territory activated (e.g., FR) = 473,933,649 HCN

Equal territory. Equal humanity.

### The Law
`Total Supply = N_activated * 473,933,649 HCN`

Where N_activated = number of territories activated.

- If 1 territory is activated: Supply = 473,933,649 HCN
- If 249 territories are activated: Supply = 118,009,478,601 HCN

No territory may receive a higher allocation than another.

### Why This Rule?
If you need 100 people to activate, big countries win first.
If you need 1 verified human, every territory has the exact same chance from day one.

This is true equality.
