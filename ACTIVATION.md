# Territory Activation - HumChain Network

### Core Principle
Territory doesn't pre-exist in HumChain. It is activated.

The network starts empty.

### The First Human Rule
The first verified human according to the HumChain Registration Protocol activates his Territory.

- 1 verified human = Territory ACTIVATED.
- No threshold, no committee, no permission.

He becomes the Genesis Human of that territory.

### What is a Territory?
A Territory is a sovereign state recognized by ISO 3166-1. 249 territories total.

### The Empty Start Rule
- No pre-mine
- No pre-allocation
- No waitlist

`total_supply = 0` at start. Supply is created only by activation.

### Upon Activation
When the first human is verified:

`473,933,649 HCN` are minted for that territory.

Fixed. Equal for all.

- 1st territory activated (e.g., CM) = 473,933,649 HCN
- 200th territory activated (e.g., FR) = 473,933,649 HCN

Equal territory. Equal humanity.

### Why this rule?
If you need 100 people, the big countries win first.
If you need 1 verified human, every territory has the exact same chance from day one.

This is true equality.
